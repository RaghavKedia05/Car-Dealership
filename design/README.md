# Design references

These are original design inputs and exports. The running application lives in `src/`; editing these mockups does not change it.

| Folder | Contents |
| --- | --- |
| `references/brand/` | Original automotive brand design notes |
| `references/showroom/` | Landing/showroom HTML mockup and screenshot |
| `references/authentication/` | Role authentication HTML mockup and screenshot |
| `references/admin-dashboard/` | Dealership operations HTML mockup and screenshot |
| `references/ai-car-finder/` | AI finder/comparison HTML mockup and screenshot |
| `archives/` | Original frontend ZIP export, retained for provenance |

Each screen folder names its HTML and screenshot after the screen, for example `showroom-mockup.html` and `showroom-preview.png`. The original design contents are preserved. Recorded application screenshots are in [docs/images](../docs/images/). Design assets are excluded from the Docker build context.
